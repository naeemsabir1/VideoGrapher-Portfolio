# The Reel — Videographer Portfolio
   
A TikTok-style swipeable video portfolio built with Next.js 15, Tailwind CSS, and ImageKit.

## Features
- Swipeable TikTok-style vertical video feed
- 7 portfolio categories
- Password-protected admin panel
- JSON file-based content management
- ImageKit video hosting integration
- Mobile-first, fully responsive
- Deployed on Vercel

## Setup
1. Clone the repo
2. Copy `.env.example` to `.env.local` and fill in your values
3. Run `npm install`
4. Run `npm run dev`
